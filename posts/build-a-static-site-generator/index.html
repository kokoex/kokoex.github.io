用 200 行代码写一个静态站点生成器

2026-11-05·技术笔记·1 分钟阅读

静态站点生成器（SSG）的本质，其实只有一句话：

把数据套进模板，写成一堆 HTML 文件。

核心流程

  1. 读取文章、页面、分类、标签
  2. 把 Markdown 渲染成 HTML
  3. 套用模板，输出文件
  4. 生成 RSS 与 sitemap

(data + template) → files

目录结构

/index.html
/posts/hello-world/index.html
/categories/notes/index.html
/feed.xml
/sitemap.xml

没有了，真的就这么简单。复杂的是细节：分页、摘要、永久链接、相对路径……但这些都不需要框架。

工具越简单，越容易长久地用下去。

完整实现见本站后台「发布静态站点」。
