写在深夜：一个关于重新开始的故事

2026-11-08·EX·生活手记·1 分钟阅读

有些夜晚，你突然想把一切归零。

不是因为失败，而是因为太熟悉了。熟悉到看得见明天的样子，熟悉到失去了惊喜。

生活需要一点留白，才能听见自己的声音。

所以我给自己做了这个小小的博客——一个可以慢慢写、慢慢改、不必讨好任何人的地方。

为什么是静态页面#

  • 打开快，没有数据库查询
  • 安全，没有后台入口暴露在公网
  • 便宜，随便一个对象存储都能托管
  • 长久，十年前的 HTML 今天依然能打开

这大概就是我想要的：把内容留在自己手里。

# 发布只需一瞬间
npm run build && echo "done"

晚安，明天见。
